# 连续性优先的 AI 短片创作

[English](README.md)

本仓库提供一个可复用的 Codex Skill，用于规划和生产多镜头 AI 短片，重点解决角色外观、角色声线、场景、道具和镜头连续性在长流程中逐步漂移的问题。

它源于一套真实的节点画布生产流程：每个短镜头独立生成，每一镜重新连接角色图和场景图，上一镜尾帧只负责构图连续，旁白与角色对白分开生成，最终剪辑替换全部视频原生音轨。

## 为什么需要这套方法

长篇生成式视频的问题往往不只是“提示词写得不够好”，而是生产结构本身不稳定：

- 每个 TTS 节点都重新猜测声线，导致角色声音前后变化；
- 用一张多人综合设定板控制所有镜头，导致角色身份混淆；
- 把 seed 当成角色身份控制；
- 视频模型自动生成的背景声、音效和声线在镜头之间跳变；
- HARD 连续性镜头没有使用上一镜头真实尾帧；
- 更新说明覆盖了完整生产表；
- 一个节点失败后，整批成功镜头被重复生成。

本 Skill 把这些问题转化为明确、可检查的生产门禁。

## 核心流程

```text
剧本
  -> 锁定角色、声音、场景和道具
  -> 完整权威原子镜头表
  -> 旁白与角色对白分开生成
  -> 每个短镜头独立生成
  -> 每镜重新连接角色图与场景图
  -> 上一镜尾帧只控制构图连续
  -> 人工检查画面、身份、口型与连续性
  -> 静音视频原生音轨
  -> 替换为确认过的旁白、对白、环境声、音效和音乐
```

核心原则很简单：模型负责生成候选，人负责批准资产，下游镜头只能使用已经批准的资产。

## 这个 Skill 能做什么

- 审计已有节点画布中的角色、声线和连续性风险；
- 建立角色、声音、场景和道具资产登记表；
- 将剧本拆成可执行的原子镜头；
- 维护包含全部镜头的权威 Manifest；
- 分离音频门禁和视频门禁；
- 按同场景小批次推进生产；
- 每个短镜头独立生成，并重新连接角色图和场景图；
- 真实尾帧只控制构图、机位、姿态和空间连续；
- 旁白与角色对白分开生成并锁定；
- 生成可直接发送给画布 Agent 的中英文提示词；
- 处理 Manifest 缺失、单节点失败和视频输出音频审核错误；
- 保留锁定干声，用于最终可控混音。

这套流程会适配实际工具能力，但不绑定某个特定视频模型或画布产品。它会先检查当前环境是否真的支持抽帧、口型同步、替换音轨或 AV Mux，而不是假设这些功能一定存在。

## 安装

将 Skill 目录复制或软链接到 Codex Skills 目录：

```bash
mkdir -p ~/.codex/skills
cp -R skills/continuity-first-short-film ~/.codex/skills/
```

如有需要，重新启动或刷新 Codex，使其发现新 Skill。

## 按起始材料选择使用方式

### 已经有完整剧本

```text
使用 $continuity-first-short-film 处理我的完整剧本。保留故事和台词，把剧本拆成独立短镜头，建立资产缺口表和完整 Manifest；旁白与角色对白分开生成；每个视频镜头重新连接角色图和场景图；尾帧只控制构图连续；最终剪辑替换全部视频原生音轨。
```

### 已经生成了一批视频

```text
使用 $continuity-first-short-film 修复我已经生成的视频片段。保留所有正确镜头，只找出角色、场景、构图、口型或声音漂移的镜头；重做时每镜重新连接角色图和场景图，上一镜尾帧只负责构图；旁白和角色对白分开生成，并制定最终替换视频音轨的方案。
```

### 没有剧本，也没有参考图片

```text
使用 $continuity-first-short-film 从零开发一部短片。我目前没有剧本和参考图片。请先帮助我确定创意、完成并确认剧本，再创建和确认可复用的角色图、场景图与声音资产，之后拆成独立短镜头；旁白与对白分开生成，最终替换视频原生音轨。
```

当请求明确涉及多镜头 AI 影片连续性或分阶段生产时，也可以由 Codex 自动选择该 Skill。

## 生产原则

1. **每个短镜头独立生成。**
2. **每个镜头重新连接锁定角色图和场景图。**
3. **上一镜尾帧只控制构图，不能控制角色或场景身份。**
4. **旁白与角色对白作为独立声音资产分开生成。**
5. **最终剪辑必须静音并替换全部视频原生音轨。**
6. **角色身份来自锁定资产，而不是名字、seed 或尾帧。**
7. **一个镜头只包含一个主要动作、一个主要机位和最多一个角色说话者。**
8. **只有经过人工确认，资产才能进入锁定状态。**
9. **只重跑失败镜头，不重跑整批成功镜头。**

## 适用范围

本仓库提供生产编排方法、数据结构、状态词汇和可复用提示词模板；它不包含视频生成模型，不用于绕过模型政策，也不保证某个画布一定提供抽帧、口型同步或最终音视频合成功能。
