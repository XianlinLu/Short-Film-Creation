# 连续性优先的 AI 短片创作

[English](README.md)

本仓库提供一个可复用的 微电影 / 短片 Skill，用于规划和生产多镜头 AI 短片，重点解决角色外观、角色声线、场景、道具和镜头连续性在长流程中逐步漂移的问题。

它源于一套真实的节点画布生产流程：默认独立生成短镜头，只对符合条件的同场景直接动作使用受控原生续写；两种模式都重新连接角色图和场景图；旁白与角色对白分开生成；最终剪辑替换全部视频原生音轨。

## 为什么需要这套方法

长篇生成式视频的问题往往不只是“提示词写得不够好”，而是生产结构本身不稳定：

- 每个 TTS 节点都重新猜测声线，导致角色声音前后变化；
- 用一张多人综合设定板控制所有镜头，导致角色身份混淆；
- 把 seed 当成角色身份控制；
- 视频模型自动生成的背景声、音效和声线在镜头之间跳变；
- HARD 连续性镜头既没有使用已批准的原生续写源，也没有上一镜真实尾帧；
- 更新说明覆盖了完整生产表；
- 一个节点失败后，整批成功镜头被重复生成。

本 Skill 把这些问题转化为明确、可检查的生产门禁。

## 核心流程

```text
剧本
  -> 锁定角色、声音、场景和道具
  -> 完整权威原子镜头表
  -> 旁白与角色对白分开生成
  -> 独立短镜头，或通过门禁的受控续写
  -> 两种模式都重新连接角色图与场景图
  -> 上一段视频只控制动作与构图连续
  -> 尾帧只作为硬连续性的后备方案
  -> 人工检查画面、身份、口型与连续性
  -> 静音视频原生音轨
  -> 替换为确认过的旁白、对白、环境声、音效和音乐
```

核心原则很简单：模型负责生成候选，人负责批准资产，下游镜头只能使用已经批准的资产。

## 受控续写

续写只是同场景直接动作连续时的效率工具，不是角色身份系统。Skill 会先读取实时节点能力，区分真正的时间线续写与普通视频参考生成。

| 情况 | 生成方式 |
| --- | --- |
| 同场景、同时间、同服装、同角色，并直接延续动作 | 通过预检后可使用原生续写 |
| 更换场景、时间、服装、年龄、说话布局或主要机位 | 独立生成 |
| 上一段已经出现脸、肢体、服装或道具漂移 | 从锁定资产独立生成 |
| 没有真正的原生续写能力 | 独立生成；用匹配剪辑，必要时才使用真实尾帧 |

即使使用续写，下一镜仍必须重新连接锁定角色图、场景图、道具图和已确认对白。上一段视频只负责动作与构图连续。每一次续写都必须先人工确认，才能成为下一次续写的源视频。

## 这个 Skill 能做什么

- 审计已有节点画布中的角色、声线和连续性风险；
- 建立角色、声音、场景和道具资产登记表；
- 将剧本拆成可执行的原子镜头；
- 维护包含全部镜头的权威 Manifest；
- 分离音频门禁和视频门禁；
- 按同场景小批次推进生产；
- 默认独立生成，只有通过资格门禁的镜头才使用原生续写；
- 无论独立生成还是续写，都重新连接角色图、场景图和必要道具；
- 使用锁定声音母带或已确认的镜头对白保持声线，而不是依赖上一段视频音轨；
- 在生成前阻止包含模糊措辞或未决备选方案的视频提示词；
- 真实尾帧只控制构图、机位、姿态和空间连续；
- 旁白与角色对白分开生成并锁定；
- 生成可直接发送给画布 Agent 的中英文提示词；
- 处理 Manifest 缺失、单节点失败和视频输出音频审核错误；
- 保留锁定干声，用于最终可控混音。

这套流程会适配实际工具能力，但不绑定某个特定视频模型或画布产品。它会先检查当前环境是否真的支持抽帧、口型同步、替换音轨或 AV Mux，而不是假设这些功能一定存在。

## 安装

将 Skill 目录复制或软链接到 Codex Skills 目录：

```bash
mkdir -p ~/.codex/skills
cp -R skills/continuity-first-short-film ~/.codex/skills/
```

如有需要，重新启动或刷新 Codex，使其发现新 Skill。

## 按起始材料选择使用方式

### 已经有完整剧本

```text
使用 $continuity-first-short-film 处理我的完整剧本。保留故事和台词，把剧本拆成原子短镜头，建立资产缺口表和完整 Manifest；旁白与角色对白分开生成；默认独立生成，只有同场景直接动作连续且通过门禁时才使用原生续写。两种模式都重新连接锁定角色图、场景图和必要道具，保持角色声音母带不变，最终替换全部视频原生音轨。
```

### 已经生成了一批视频

```text
使用 $continuity-first-short-film 续写或修复我已经生成的视频片段。保留所有正确镜头，先核查是否存在真正的原生续写能力；只有同场景直接动作连续时才续写，否则独立生成下一镜或重做失败镜头。两种模式都重新连接锁定角色图和场景图，保持角色声音母带不变；旁白和对白分开生成，最终替换视频原生音轨。
```

### 没有剧本，也没有参考图片

```text
使用 $continuity-first-short-film 从零开发一部短片。我目前没有剧本和参考图片。请先帮助我确定创意、完成并确认剧本，再创建和确认可复用的角色图、场景图与声音资产，之后拆成原子短镜头；默认独立生成，只对符合条件的同场景直接动作使用受控续写；旁白与对白分开生成，最终替换视频原生音轨。
```

当请求明确涉及多镜头 AI 影片连续性或分阶段生产时，也可以由 Codex 自动选择该 Skill。

## 生产原则

1. **独立生成短镜头是默认方式。**
2. **原生续写只用于通过门禁的同场景直接动作连续。**
3. **独立生成或续写时都必须重新连接锁定角色图和场景图。**
4. **上一段视频只控制动作与构图，不能控制角色身份或声线。**
5. **尾帧是硬连续性的后备方案，不是身份参考。**
6. **旁白与角色对白作为独立声音资产分开生成。**
7. **最终剪辑必须静音并替换全部视频原生音轨。**
8. **角色身份来自锁定资产，而不是名字、seed、尾帧或上一段视频音轨。**
9. **每一次续写都要人工确认后才能继续下一次。**
10. **每条视频提示词只能有一个确定方案；模糊表达必须在生成前被阻止。**
11. **只重跑失败镜头，不重跑整批成功镜头。**

本地提示词可以使用确定性检查脚本：

```bash
python3 skills/continuity-first-short-film/scripts/check_video_prompt.py prompt.txt
```

## 适用范围

本仓库提供生产编排方法、数据结构、状态词汇和可复用提示词模板；它不包含视频生成模型，不用于绕过模型政策，也不保证某个画布一定提供抽帧、口型同步或最终音视频合成功能。
